# What the project has to do

Our own summary of the course requirements for the final project.

- Java back end. A gui is allowed but it does not count as a feature.
- Each member builds a web crawler for one website and 1 to 2 other features.
- Use 3 to 5 different concepts from the course and a variety of data structures.

## Mandatory features

| Feature | What it means for us |
|---|---|
| Web crawler | crawl the pricing page of each provider and follow links to its model pages |
| HTML parser | read the price tables out of the html into one model format |
| Spell checking | build a vocabulary from all crawled words and suggest close words with edit distance |
| Word completion | complete a prefix with the most frequent words |
| Frequency count | how many times a word is in one url |
| Search frequency | remember what was searched and how many times |
| Page ranking | rank pages by how many times the keywords are in them |
| Inverted indexing | word to pages and positions so search does not read every page |
| Data validation with regex | check user input like token amounts, money and dates |
| Finding patterns with regex | find prices, context sizes, dates and model ids in the text |

## Extra features we planned

- Workload cost calculator and recommendation
- Side by side comparison and a model card
- Warnings for price changes and a list of free models
- Scheduled email report with email login (later)

## Final report and presentation need

- group name, members and the variant
- who did what with the names of the java files
- data structures and algorithms for each feature
- screenshots of each feature
- references
- 7 to 10 minute presentation with a live demo and questions for each member
