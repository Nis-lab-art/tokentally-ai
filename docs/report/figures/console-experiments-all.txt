== Shrijana Karki

      top 10                              22.86

      about the same. Why: the heap only decides the order. Most of the time goes into counting keyword hits in the index, so the gap is small on 81 pages.
page ranking: 1 keyword against 4 keywords
      1 keyword                            8.81
      4 keywords                          19.53   (microseconds per search)
      1 keyword is 2.2x faster. Why: 4 keywords cost about twice as much as 1, not 4 times, because pages that have several keywords are merged in one map.
data validation: check a token amount with the regex
      good value 2.5M                       674
      bad value                             105   (nanoseconds per check)
      bad value is 6.4x faster. Why: a bad value fails the pattern early, so it costs less than reading a good one. A hostile input can not slow the program down.
