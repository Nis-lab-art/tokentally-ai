Tokens used for built-in tools are billed at the chosen model’s per-token rates.
GB refers to binary gigabytes (also known as gibibytes), where 1 GB is 2^30 bytes.
Agent Kit’s free storage allowance applies per account per month.
Web search content tokens are tokens retrieved from the search index and fed to the model alongside your prompt to generate an answer.
For gpt-4o-mini and gpt-4.1-mini with the non-preview web search tool, search content tokens are billed as a fixed block of 8,000 input tokens per call.
File search tool call pricing applies to the Responses API only.
Container pricing includes Hosted Shell and Code Interpreter .
Eligible container sessions will be billed by the minute, with a 5-minute minimum per session.

GPT-6.2 Sol accepts text and image inputs and produces text. Use it with the
Responses API to call tools such as web search and computer use, or to delegate
work to subagents with the Multi-agent beta .
The API rejects requests that set reasoning effort to none .
The Responses API supports discounted background completion windows in public beta.

922,000 max input tokens
128,000 max output tokens

Pricing
Prices are per 1M tokens. See the pricing page for processing tiers and billing details.

Input

The cache write price is for 30 minutes of retention. A 12-hour cache write costs $5 per million tokens for short-context requests at Standard pricing.
For requests with more than 272K input tokens, input and cache rates double and output costs 1.5 times the short-context rate for the full request.
Batch costs 50% of Standard rates. Fast mode costs twice the Standard rate for the same context length.
Ultrafast costs 3 times the Standard rate through February 28, 2027, and 6 times the Standard rate starting March 1, 2027 (Pacific time).

GPT-Realtime-Translate is a streaming speech-to-speech translation model for live multilingual audio experiences. It uses a dedicated realtime translation endpoint and returns translated audio plus transcript deltas while source audio is still arriving. GPT-Realtime-Translate is priced by audio duration rather than text tokens.
